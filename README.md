# 米家中枢屏幕工作台

面向 VIEWE `UEDX80480070E-WB-A`（ESP32-S3-N16R8、800x480 RGB、GT911）的中文可视化 ESPHome/LVGL 配置、编译和烧录工具。

## 仓库

- 远程仓库：<https://github.com/littlewuxiao-ux/mihome-display-studio>
- 默认分支：`main`
- 更新规则：每次功能更新后补充本README的“更新记录”，运行测试，通过后提交并推送到远程仓库。

## 启动

```powershell
python -m pip install -r requirements.txt
python main.py
```

工具调用当前 Python 环境中的 ESPHome，不包含独立编译内核。启动后会自动打开本地浏览器工作台，默认地址为 <http://127.0.0.1:8765>；当前项目保存在`projects/current-project.json`，历史备份位于`projects/backups/`，生成配置和编译结果位于`build/`。

## 媒体支持

- 静态图片：支持PNG、JPEG、WebP和BMP，单文件最大8MB。图片会按画布尺寸转换为RGB565并编译进固件，PNG/WebP可保留透明通道。
- 动图：ESPHome支持GIF帧动画，但大尺寸或高帧率内容会快速占满16MB Flash并增加PSRAM压力，本版本暂未开放。
- 视频：ESPHome/LVGL没有适用于该板卡的通用MP4/H.264视频解码链路，本版本不支持视频插入。

## 当前功能

- 实体配置：显示实体用于读取数据；“操作另一个实体”留空时，点击操作作用于显示实体。“设为指定数值”会直接写入目标值，“增加/减少一个步长”使用 HA 助手自身配置的步长。
- 纯数值显示：选择数值助手或数值实体后，将外观设为“只显示数值（无加减按钮）”。需要调节时，可切换为滑块或滑块加数值。
- 页面跳转：基础控制 → 布局与层级 → 是否切换页面，可以为组件指定目标子页面。开启后，点击优先换页，实体仍可用于显示。
- 图标与状态：固定图标、圆环内图标、状态图标的字号、位置和颜色会写入固件；旧项目中意外隐藏的独立图标会在首次加载时恢复。之后主动关闭“显示固定图标”仍会生效。
- 电池显示：横向、竖向和环形电量显示使用实际 INA 数据。电量是从设置的初始百分比开始积分的估算值，需要电流经过分流电阻；未取得有效读数时显示 `--`。

- 图形与图片：统一入口创建矩形，并可在属性栏切换为椭圆、圆形或图片；独立横线使用直接的 LVGL `line` 向量节点，不再生成矩形容器。

- 几何调整：椭圆支持横向/纵向半径，圆形保持等半径，线条支持长度和`-180°`至`180°`方向。
- 文字编辑：所有图形和图片都可以叠加文字；选中组件后可直接在画布中编辑，并分别设置字号、颜色和对齐。
- 状态组件：提供圆形和柱状状态栏，可设置范围、预览值、颜色以及百分比/原始数值显示。
- LVGL 原生控件：可视化插入滑块、开关、复选框和下拉选择；支持范围、预览值、初始开关状态及下拉选项，并生成原生 ESPHome/LVGL 控件配置。
- 虚拟按钮：支持按压缩放、按压变暗或关闭反馈，并可调用Home Assistant操作。
- 多界面：支持新增、删除界面、界面切换按钮、鼠标滚轮切换界面和组件层级调整；删除界面时组件和跳转目标会迁移到保留界面。

- 数值操作：鼠标悬停在数字或滑块输入框上时，可以使用滚轮增减数值。
- 项目管理：项目数据带`schema_version`，兼容旧项目格式，支持结构校验、JSON项目导入和脱敏导出；固件版本写入ESPHome项目元数据。


- 安全保护：导出项目默认清空WiFi密码、API密钥和OTA密码，非法项目不会覆盖当前项目。
- 可靠性：每次保存前自动保留上一版本，最多保存20份备份，支持从工作台恢复并阻止备份路径穿越。
- 编辑历史：支持最近50步撤销和重做，覆盖画布拖拽、组件和项目属性、页面及层级操作，并提供`Ctrl+Z`、`Ctrl+Y`快捷键。
- 崩溃恢复：未保存编辑会临时写入浏览器本地存储，重新打开工作台时可选择恢复；恢复草稿不保存WiFi密码、API密钥或OTA密码。

- 设备可靠性：可通过串口读取芯片、MAC、Flash和晶振信息；烧录前必须识别并确认目标设备，后端会再次校验串口；烧录成功后重新识别设备并核对MAC，最多重试三次。
- 固件更新：已完成首次USB烧录且设备在线后，可在顶部切换到“无线 OTA”，使用设备IP或`设备名.local`更新固件；完成后会通过ESPHome API核对运行版本。
- 设备发现：切换到无线OTA时自动通过mDNS发现局域网ESPHome设备，并按MAC保存名称、IP和版本；设备IP变化后会更新原记录并继续作为烧录目标候选项。
- 横线组件：单独插入横线，默认不创建文字标签，也不要求中文字体；纯横线项目可以生成不含自定义字体资源的配置。
- 透明度：形状填充不透明度支持0到100，0表示完全透明，并同步到画布预览和LVGL `bg_opa`。
- 资源分析：可以统计图片、字体、生成配置和已编译固件大小，按16MB Flash给出占用比例和风险提示。
- 趋势图坐标：浏览器预览与固件共用一致的绘图区，每个纵轴刻度带水平虚线，横轴“现在”标签保留独立空间。
- INA电量计量：INA219/INA226支持按电压、电流和采样时间累计剩余Wh，断电后从Flash恢复；充电、放电和20%低电状态可使用不同颜色。
- 显示设置：本机设置页提供运行时亮度滑块和息屏时间下拉选择，支持长亮、30秒、1/2/5/10/30分钟并持久化选择。









## Home Assistant准备

屏幕推荐使用`米家设备 -> Home Assistant -> ESPHome屏幕`的数据链路。ESPHome设备通过原生API与HA通信，并不直接连接`ha_xiaomi_home`的内部MQTT；项目中的HA地址目前作为记录字段保留，实际连接方向是HA主动连接屏幕设备。

1. 在HA的“设置 -> 设备与服务”中配置官方`Xiaomi Home`集成；官方集成未覆盖的设备可按实际环境使用HACS中的`Xiaomi Miot Auto`。
2. 确保集成登录的账号和地区与米家App一致，然后在“开发者工具 -> 状态”中找到设备实体ID。
3. 首次烧录后，在HA中添加发现的ESPHome设备，并填写工作台配置的API加密密钥。
4. 在工作台选择图形、图片或状态栏，填写实体ID，例如`sensor.living_room_temperature`或`climate.living_room`。
5. 温度、湿度、功率和占用率选择“数值”；空调、门锁、灯光等开关/模式选择“设备状态”。圆形和柱状状态栏只能绑定数值实体。
6. 按钮需要控制设备时，填写HA操作和实体，例如`light.toggle`与`light.living_room`，并在ESPHome集成中允许设备执行Home Assistant操作。

CPU、内存和磁盘数据可通过HA“系统监视器”集成提供；PC或服务器的CPU/GPU数据可通过Glances接入。常见实体包括`sensor.processor_use`、`sensor.memory_use_percent`和`sensor.pc_gpu_load`，实际名称以HA开发者工具中显示的实体ID为准。

如果米家设备把数值放在实体属性中，例如空调的`current_temperature`，可先在HA中创建模板传感器，再把生成的`sensor`实体绑定到状态栏：

```yaml configuration.yaml
# ... existing configuration ...
template:
  - sensor:
      - name: "客厅空调当前温度"
        unique_id: living_room_ac_current_temperature
        unit_of_measurement: "°C"
        state: >
          {{ state_attr('climate.living_room', 'current_temperature') }}
```

## 模块

- `web/index.html`：浏览器工作台结构
- `web/styles.css`：响应式工作台、屏幕边框和属性面板样式
- `web/app.js`：画布拖拽、图片上传、项目编辑和任务日志交互
- `app/web_server.py`：本地HTTP API、项目保存、串口和ESPHome任务管理
- `app/models.py`：项目和组件数据模型
- `app/yaml_generator.py`：板卡、LVGL、字体、图片和HA实体YAML生成
- `app/lvgl_compiler.py`：组件外观、页面跳转、HA 与本机数据更新
